# 2.2章节（CPU调度）

---

### 1. 核心概念（4个）
1. **三级调度机制**（高级/作业、中级/内存、低级/进程调度）
2. **调度的时机与过程**（尤其是“什么时候不能调度”，以及上下文切换与模式切换的区别）
3. **调度评价指标**（周转时间、带权周转时间等推导体系）
4. **经典调度算法的设计思想**（从FCFS到多级反馈队列的演进逻辑）

### 2. 哪些需要画图（抛开书本自己画）
1. **CPU三级调度关系图**（对应图2.8，画出作业、就绪队列、挂起队列、CPU之间的流转关系）
2. **多级反馈队列调度流程图**（对应图2.10，画出新进程进入、时间片用完降级、高优先级抢占的过程）
3. **各种算法的甘特图（极度重要！）**（这是408解题的核心工具，必须能够根据到达时间和运行时间画出横轴为时间的执行流图）

### 3. 哪些需要推演（在纸上写出推演过程）
1. **调度评价指标计算公式**：推演`完成时间` -> `周转时间` -> `带权周转时间` 的计算链条，以及推演多个批处理作业的`平均`指标。
2. **高响应比优先（HRRN）公式**：推演响应比公式 $= (等待时间+运行时间)/运行时间$ 是如何同时做到“类似FCFS（等待越久响应比越高）”和“类似SJF（运行越短响应比越高）”的。
3. **抢占式最短剩余时间优先（SRT）推演**：推演当新进程到达时，如何与当前运行进程的“剩余时间”进行比对并发生上下文切换。

### 4. 哪些需要对比（列出对比表格）
1. **高级 vs 中级 vs 低级调度**（对比：调度对象、发生频率、功能目的）
2. **上下文切换 vs 模式切换**（对比：是否跨进程、是否全在内核态、开销大小）
3. **非抢占式 vs 抢占式调度**（对比：发生调度的时机、吞吐率、适用系统）
4. **七大调度算法大比拼**（对比：FCFS、SJF、HRRN、优先权、RR、多级队列、多级反馈队列的——**是否可抢占、优缺点、是否会导致饥饿、适用系统**）

### 5. 学习任务清单（4小时=8个番茄钟，按优先级排序）

#### **模块一：调度框架与机制（1小时）**
**【任务1】理清三级调度与调度程序（30分钟）**
*   **做什么**：掌握作业、内存、进程调度的层级关系，以及调度程序的结构。
*   **怎么做**：闭卷在白纸上画出“外存后备队列 ->(高级调度)-> 内存就绪队列 <->(中级调度/挂起)-> 内存/外存 -> (低级调度)-> CPU”的流转图。
*   **如何检验**：指着你画的图，用自己的话解释为什么“高级调度频率最低，低级最高”，并能说出排队器、分派器、上下文切换器分别在图中的哪个环节起作用。

**【任务2】死磕“调度时机”与“进程切换”（30分钟）**
*   **做什么**：明确什么时候必须调度，什么时候绝对不能调度。
*   **怎么做**：对比“原语/原子操作/中断处理时”与“系统调用完成/一般临界区内”的区别。画一个对比表格区分“上下文切换”与“模式（态）切换”。
*   **如何检验**：做课后选择题 **06、08、41、55、57**。如果能准确选出为什么临界区内（如等待打印机）可以调度，就算过关。

#### **模块二：核心指标与基础算法推演（1.5小时）**
**【任务3】手撕调度评价公式（30分钟）**
*   **做什么**：搞透周转时间、带权周转时间、等待时间、响应时间的内在逻辑。
*   **怎么做**：不要背公式！假设你早上8点去银行（提交），排队1小时（等待），办业务2小时（运行），然后在纸上推导你的周转时间和带权周转时间。
*   **如何检验**：合上书，写出$T_{周转}、W_{带权周转}$的公式。做课后选择题 **15、21**，算对即过关。

**【任务4】算法推演一：FCFS、SJF、HRRN（30分钟）**
*   **做什么**：掌握单道/非抢占式环境下的基本算法。
*   **怎么做**：阅读教材表2.2和2.3。**用铅笔在白纸上自己画出甘特图**，验证书上的完成时间是否正确。重点推演HRRN的响应比公式。
*   **如何检验**：不看书上的解析，自己画图做出选择题 **18、19、45**。

**【任务5】算法推演二：抢占式调度（SRT与抢占式优先级）（30分钟）**
*   **做什么**：这是408**最爱考**的计算类型，掌握新进程到达时的抢占逻辑。
*   **怎么做**：牢记一点——**“只有伴随新进程到达就绪队列时，才需要判断是否抢占”**。重点看抢占式SJF（最短剩余时间优先）。
*   **如何检验**：直接挑战选择题中的硬核计算题 **26、28、47、52**。用“广义甘特图”画横轴一步步推演。计算结果一致即彻底掌握。

#### **模块三：高级算法与多处理机（1.5小时）**
**【任务6】算法推演三：时间片轮转（RR）（30分钟）**
*   **做什么**：理解时间片大小的权衡，以及RR算法的执行流。
*   **怎么做**：推演当时间片太大（退化为FCFS）和太小（上下文切换开销过大）的后果。注意：时间片用完后，进程是回到**就绪队列末尾**。
*   **如何检验**：挑战选择题 **54**，以及综合题 **06的第2问（时间片轮转计算）**。

**【任务7】终极BOSS：多级反馈队列（MFQ）（30分钟）**
*   **做什么**：理解408最青睐的综合性调度算法的设计逻辑。
*   **怎么做**：画出图2.10。自己向自己解释：为什么它能同时照顾短进程（响应快）、长进程（不饿死，在底部大时间片执行）、I/O进程（高优先级队列完成）？
*   **如何检验**：做选择题 **29、48、49**。只要能理清“只有上层队列空了才执行下层”以及“时间片用完降级”的逻辑即可。

**【任务8】收尾框架与对比（30分钟）**
*   **做什么**：处理多处理机调度（AMP/SMP）概念，并完成全局框架梳理。
*   **怎么做**：列出一个横向大表（对应教材表2.4），闭卷填写七大算法的【是否抢占】、【优缺点】、【是否饥饿】。
*   **如何检验**：闭眼能在脑海中浮现出整个2.2节的知识树。做做文字性选择题 **35、39、43**，测试对“饥饿现象”的判断。
