# 2.3 同步与互斥

---

## 1. 核心概念（5个）

1. **临界资源与临界区**：临界资源的定义、临界区的四段结构（进入区/临界区/退出区/剩余区）、互斥准则（空闲让进、忙则等待、有限等待、让权等待）
2. **软件/硬件互斥实现方法**：单标志法→双标志先检查→双标志后检查→Peterson算法的演进逻辑；TS指令、Swap指令、中断屏蔽的原理与优缺点
3. **信号量机制**：整型信号量 vs 记录型信号量；P/V操作的语义；用信号量实现互斥、同步、前驱关系的三种范式
4. **经典同步问题**：生产者-消费者、读者-写者（读者优先/写者优先）、哲学家进餐——问题建模与PV操作解法
5. **管程**：管程的定义与四部分组成、条件变量wait/signal与信号量P/V的区别、管程如何自动保证互斥

## 4. 需要对比的概念（6组）

| 对比项                                 | 对比维度                                                     |
| -------------------------------------- | ------------------------------------------------------------ |
| ① 同步 vs 互斥                         | 制约来源（合作 vs 竞争）、信号量初值（0 vs 1）、P/V位置（不同进程 vs 同一进程成对） |
| ② 四种软件算法                         | 标志变量设计、违反的准则、失败的执行序列                     |
| ③ TS指令 vs Swap指令 vs 中断屏蔽       | 原子性保证方式、是否适用多处理器、是否让权等待               |
| ④ 整型信号量 vs 记录型信号量           | 是否忙等待、是否有等待队列、是否满足让权等待                 |
| ⑤ 互斥锁（自旋锁）vs 记录型信号量      | 等待方式（忙等 vs 阻塞）、适用场景（多处理器短临界区 vs 通用） |
| ⑥ 管程条件变量wait/signal vs 信号量P/V | 是否有计数值、signal无等待者时是否有效果、互斥由谁保证       |

## 5. 学习任务清单（按优先级）

### 任务1：画框架总图（25min）
- **做什么**：在一张A4纸上画出2.3节的知识框架树，一级节点为：基本概念→互斥实现方法（软件/硬件）→互斥锁→信号量→经典同步问题→管程
- **怎么做**：边读目录边画，每个节点写2-3个关键词，不要抄句子
- **检验**：合上书，能否对着框架图口述每个节点讲什么（30秒/节点）

### 任务2：推演四种软件算法 + Peterson（30min）
- **做什么**：不看书，手写四种算法的代码框架，标注每种违反了哪条准则，并画出导致错误的执行序列
- **怎么做**：按"算法一→二→三→四"的演进顺序，每种算法先写代码→再构造反例→标注违反的准则
- **检验**：做选择题36、37、38、48题，全对即通过

### 任务3：推演信号量P/V操作 + 实现互斥/同步/前驱（30min）
- **做什么**：手写记录型信号量的wait/signal伪代码；分别写出用信号量实现互斥（初值1）、同步（初值0）、前驱关系（图2.11）的代码模板
- **怎么做**：先默写wait/signal定义→画S.value变化轨迹图→默写三种范式代码→画前驱图标信号量
- **检验**：做选择题03、17、18、24、25、26、30题，错误不超过1道

### 任务4：画图+推演生产者-消费者问题（30min）
- **做什么**：画出标准生产者-消费者的信号量流程图；推演死锁场景；做水果盘变体
- **怎么做**：先默写标准代码→交换P(mutex)和P(empty)位置，手动推演死锁→写水果盘问题代码
- **检验**：做综合题04（装配车间），能独立写出完整PV代码且无死锁

### 任务5：画图+推演读者-写者问题（30min）
- **做什么**：画出读者优先方案的流程图，标注count/mutex/rw配合；理解写者优先方案增加信号量w的作用
- **怎么做**：先默写读者优先代码→模拟"2读者→1写者→1读者"的执行过程→对比写者优先代码差异
- **检验**：做选择题44；能口述"为什么写者优先需要增加信号量w"

### 任务6：画图+理解哲学家进餐问题（25min）
- **做什么**：画5人5筷示意图；推演同时拿左筷的死锁场景；写出三种解决方案的思路（限4人/奇偶编号/同时拿两筷）
- **怎么做**：默写死锁版代码→推演死锁→选"同时拿两筷"方案写完整代码
- **检验**：做选择题45；做综合题23（2019真题），能写出完整方案

### 任务7：对比总结 + 管程概念（25min）
- **做什么**：在纸上画出任务4中列出的6组对比表格；阅读管程部分，重点理解条件变量wait/signal与信号量P/V的区别
- **怎么做**：每组对比列2-3个维度，用表格形式；管程部分读一遍后用自己的话写3句话总结
- **检验**：做选择题28、29、52、54；能说清"管程的signal在无等待进程时无效果，而V操作一定会+1"

### 任务8：真题实战（25min）
- **做什么**：限时做2020真题（综合题24-前驱关系）、2024真题（综合题28-缓冲区操作）、2025真题（综合题29-植树问题）
- **怎么做**：每题限时8分钟，独立完成后对答案
- **检验**：3道综合题至少做对2道，信号量定义和PV位置均正确

## 7. 何时向AI求助

| 情况                                                         | 行动                                                    |
| ------------------------------------------------------------ | ------------------------------------------------------- |
| 推演某个算法的执行序列时卡住（如Peterson两进程同时请求时turn的最终值） | ✅ 向AI请求逐步模拟                                      |
| 写PV代码时不确定P/V的位置或信号量初值                        | ❌ 先自己尝试→对答案→仍不理解再问AI解释为什么            |
| 记不住某个算法的代码细节                                     | ❌ 不要问，回去推演理解逻辑，代码自然记住                |
| 综合题写完后答案不同，不确定谁对                             | ✅ 把你的方案和标答都给AI，请它分析差异和可能的错误      |
| 读者-写者"写者优先"方案中信号量w的作用想不明白               | ✅ 向AI请求模拟"有写者等待时，新读者到达"的执行过程      |
| 遇到变体问题（如2025植树题）不知如何建模                     | ✅ 先尝试10分钟→写不出来再向AI描述你的思路，请它指出问题 |
