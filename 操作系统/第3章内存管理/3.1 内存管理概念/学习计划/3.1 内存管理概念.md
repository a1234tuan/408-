# 3.1 内存管理概念

---

## 1. 核心概念（5个）

1. **逻辑地址 → 物理地址的映射机制**（地址变换的本质）
2. **连续分配三种方式**（单一/固定/动态分区，及其碎片问题）
3. **基本分页**（页表结构 + 地址变换过程 + TLB）
4. **多级页表**（解决什么问题，带来什么代价）
5. **分段 vs 分页 vs 段页式**（本质区别 + 各自适用场景）

## 3. 需要推演的内容（4项）

1. **地址变换计算**：给定逻辑地址A，推演 P=A/L、W=A%L、E=b×L+W 的完整过程
2. **TLB有效存取时间**：EAT = 命中率×(TLB时间+1次访存) + 未命中率×(TLB时间+2次访存)
3. **两级页表空间节省推导**：32位地址空间，4KB页，单级需要多少内存 → 两级如何按需分配
4. **动态分区分配算法比较**：对同一请求序列，手动模拟首次/最佳/最坏适应的分配结果差异

---

## 4. 需要对比的概念（4组）

| 对比组                          | 关键区分点                                        |
| ------------------------------- | ------------------------------------------------- |
| **静态重定位 vs 动态重定位**    | 地址转换时机、能否移动进程                        |
| **内部碎片 vs 外部碎片**        | 哪种分配方式产生哪种碎片                          |
| **分页 vs 分段**                | 单位性质(物理/逻辑)、地址维度、碎片类型、共享方式 |
| **首次/邻近/最佳/最坏适应算法** | 空闲链排序方式、碎片倾向、大作业支持能力          |

## 7. 何时需要向AI求助

遇到以下情况再问：

1. **推演卡住**：手算地址变换时，不知道如何从逻辑地址拆出页号和偏移
2. **概念混淆**：看完对比表，还是分不清"为什么分段是二维地址空间"
3. **真题看不懂**：2019真题68题（虚拟地址20501225H的页目录号计算）做错了想对答案
4. **推导不出来**：两级页表如何节省连续内存空间的逻辑推导想不通
5. **发现矛盾**：觉得某两个知识点之间相互矛盾（大概率是理解有偏差）

> ⚠️ **不需要问AI的情况**：选择题做错了但答案有解析 → 先看解析，看完还不懂再问
